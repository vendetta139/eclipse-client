# ✦ Eclipse Client v2.0 — Minecraft Fabric 1.21.1+

Премиальный клиентский мод нового поколения: умная авто-ротация донат-префиксов, интерфейс **Cyberpunk / Dark Glassmorphism** с неоновыми градиентами, живым поиском и полный комплекс PvP и атмосферных визуалов.

Ставится **только на клиент**. Работает на любых серверах Minecraft 1.21 / 1.21.1+.

---

## 🚀 Нововведения в Eclipse v2.0

1. **🔥 Полная поддержка Minecraft 1.21+ (1.21.1 Fabric)**:
   - Переписан на Java 21 и Fabric Loom 1.8.
   - Поддержка новой архитектуры рендеринга 1.21.1 (`BufferRenderer`, `RenderTickCounter`, `SkinTextures`).
   - Нативная интеграция с Fabric API (`WorldRenderEvents.LAST`).

2. **🔮 Полный редизайн меню (Cyberpunk & Dark Glassmorphism)**:
   - **Глубокий обсидиановый фон** (`#090D14`) с мягким фиолетово-бирюзовым неоновым свечением (Purple Glow `#A855F7` & Cyan Glow `#06B6D4`).
   - **Живой поиск параметров**: поле `🔍 Поиск...` в шапке меню для мгновенной фильтрации любой настройки.
   - **Интерактивные тумблеры**: современные анимированные переключатели iOS / Cyberpunk стиля с плавным ходом бегунка.
   - **Плавные слайдеры**: перетаскивание мышью в реальном времени с отображением точных значений.
   - **Индикатор статуса в шапке**: бейдж `● РОТАЦИЯ: ВКЛ` / `○ ПАУЗА` для быстрого переключения авто-смены префиксов в 1 клик.
   - **Монитор производительности**: живой счетчик FPS и пинга прямо в заголовке меню.
   - **Красивый предпросмотр префиксов**: блок симуляции чата Minecraft с цветными кодами (`&a`, `&c`, `&l`, `&o` и `&#HEX`).

3. **💎 Ребрендинг в Eclipse Client**:
   - Новое чистое, дерзкое и технологичное имя взамен устаревшего donor-prefix.
   - Актуализированные языковые файлы и категории клавиш управления.

## 🛠 Сборка мода

Требуются JDK 21 (или Gradle автоматически загрузит через тулчейн) и доступ в интернет.

```bash
./gradlew build
```

Готовый файл мода появится в папке:
`build/libs/eclipse-client-2.0.0.jar`

---

## 📥 Установка

1. Установите **Fabric Loader** для **Minecraft 1.21.1** через [Fabric Installer](https://fabricmc.net/use/).
2. Скачайте **Fabric API** для 1.21.1 (с Modrinth или CurseForge).
3. Поместите `fabric-api-*.jar` и `eclipse-client-2.0.0.jar` в папку `.minecraft/mods`.
4. Запустите Minecraft через профиль Fabric 1.21.1.

## 🎮 Управление и меню в игре (Клавиша P)

Нажмите клавишу **P** (настраивается в *Настройки → Управление → категория "Eclipse Client"*):

### 1. ✦ Префиксы
- **Очередь префиксов**: карточки с живым превью, кнопками `▲`/`▼` для изменения порядка, `►` для моментальной отправки команды на сервер для теста, и `✕` для удаления.
- **Индикатор активного префикса**: карточка, которая сейчас активна на сервере, подсвечивается неоновым контуром со счетчиком `● АКТИВЕН [Смена: Nс]`.
- **Параметры ротации**: кулдаун с кнопками `[-5с]` / `[+5с]`, редактирование шаблона команды (по умолчанию `prefix set %s`).
- **Кнопка «Сохранить и применить»**.

### 2. ⚔ Бой & PvP
- **Custom Hurt Color**: замена красной вспышки при получении урона на любой цвет или переливающуюся радугу с регулировкой прозрачности.
- **No Hurt Cam**: отключение тряски и наклона камеры при получении ударов.
- **Target Aura Ring (3D)**: вращающийся светящийся 3D-круг под ногами цели.
- **Jump Circles**: расходящиеся неоновые волны на земле при прыжках и приземлениях.
- **HitMarkers & Hit Sound**: тактический крестик при попадании и звонкий щелчок удара.
- **Damage Numbers**: всплывающие 3D-цифры урона над головами врагов.
- **Множитель частиц критов**: `1x`, `2x`, `4x`, `8x`.

### 3. 🗡 Анимации
- **1.7 Swing**: быстрый классический взмах мечом 1.7.
- **BlockHit**: плавная анимация блока мечом при нажатии ПКМ.
- **Low Shield**: заниженный щит во второй руке для максимального обзора.
- **Hand Scale**: ползунок масштабирования рук (`0.5x` - `1.4x`).
- **3D Физика предметов**: лежащие на земле предметы под углом.

### 4. 🌌 Мир & Туман
- **Fullbright**: максимальная яркость без зелий ночного зрения.
- **Low Fire**: опускание текстуры огня вниз экрана.
- **Custom Fog & No Fog**: цветной неоновый туман либо режим кристальной дальности без тумана.
- **Custom Glint**: кастомный цвет блеска зачарованных предметов.
- **No Rain**: отключение осадков.
- **Time Changer**: фиксированное время суток (День / Закат / Ночь).

### 5. 📊 HUD & Оверлеи
- **✥ Интерактивный HUD Редактор**: визуальное перетаскивание любых элементов интерфейса прямо на экране игры.
- **Custom Crosshair**: неоновый тактический прицел с точкой.
- **Target HUD**: стеклянный виджет в центре с аватаркой, дистанцией и полосой здоровья противника.
- **Watermark HUD**: компактный инфо-бар с FPS и пингом.
- **Keystrokes & CPS**: счетчики кликов и отображение клавиш движения.
- **Armor HUD & Potion HUD**: отображение прочности брони и активных зелий.
- **Totem Pop Counter**: золотые уведомления о снятых тотемах.

### 6. 🎨 Тема & Стиль
- **Modern HD Шрифт (TrueType)**: кристально четкий сглаженный векторный шрифт Segoe UI с субпиксельным 2.5x оверсэмплингом.
- **Стиль серверных панелей**: кастомное затемнение, неоновые рамки и мягкое свечение вокруг инвентаря и сундуков.
