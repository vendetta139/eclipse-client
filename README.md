# Eclipse Client

Клиентский мод для Minecraft 1.21.11 (Fabric) с набором визуальных твиков, HUD-редактором и авто-ротацией префиксов. Работает на любых серверах и ставится только на клиент.

## Что внутри

- **AutoPrefix** — очередь префиксов с заданным интервалом, шаблоном команды и предпросмотром цветовых кодов (`&` и `&#HEX`).
- **HUD и редактор** — Watermark, FPS, CPS, Keystrokes, Armor HUD, Potion HUD и Target HUD с перетаскиванием, масштабированием и привязкой к сетке.
- **Custom Crosshair** — настраиваемый прицел (форма, размер, толщина, зазор, цвет).
- **HitMarker** — крестик и звук при попадании по цели.
- **NoHurtCam** — отключает тряску камеры при получении урона.
- **ViewModel** — настройка масштаба рук, `BlockHit` и заниженный щит (`SmallShield`).
- **Fullbright** — полная яркость без эффекта ночного зрения.
- **NoFog** — убирает туман.
- **LowFire и NoOverlay** — опускает огонь и скрывает оверлеи удушья, тыквы и воды.
- **CameraClip** — камера от третьего лица не упирается в блоки.
- **TimeChanger и WeatherChanger** — локальное время суток и отключение осадков.
- **UpdateChecker** — проверка новых релизов на GitHub с уведомлением в чат (можно отключить в настройках).

## Управление

- `Right Shift` — открыть ClickGUI (также кнопка в главном меню).
- `P` — открыть меню настроек и префиксов (клавишу можно переназначить в настройках управления).
- **HUD-редактор** открывается кнопкой из ClickGUI или основного меню мода.
- Конфиг хранится в `config/eclipse-client.json`.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.11**.
2. Скачайте **Fabric API** под **1.21.11**.
3. Положите `fabric-api-*.jar` и `eclipse-client-*.jar` из [Releases](https://github.com/vendetta139/eclipse-client/releases) в папку `.minecraft/mods`.

## Сборка

Требуется JDK 21:

```bash
./gradlew build
```

Готовый файл появится в `build/libs/eclipse-client-2.0.0.jar`.
